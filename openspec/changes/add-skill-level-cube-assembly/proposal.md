# Proposal

## Why

Тема диплома — «Децентрализованная координация двух роботов через Bi-JEPA» — требует задачи, в которой координация измерима и содержательна: неаддитивная общая награда, приватная случайность партнёра, неполная наблюдаемость. Текущая среда (однослойный «поворотный» кубик, фиксированные роли, один ход) даёт слишком тонкий слой координации для предзащиты 2026-12-14: демонстрация «кубик собирается агентами» невозможна на одном повороте грани. Одновременно joint-level обучение с нуля (линия 2.1) показало, что end-to-end моторика не схватывается — нужен skill-level уровень управления.

## What Changes

- Новая среда уровня навыков поверх физики `FaceTurn`: политика каждой руки выбирает дискретный скриптовый примитив; моторика примитивов не обучается (осознанное допущение диплома), обучаются выбор и координация.
- Многослойный кубик: корпус-ядро + 6 внешних слоёв на revolute-суставах (обобщение текущего однослойного «турнтейбла»); ходы Kociemba используют только внешние слои.
- Примитивы переворота кубика холдером (подъём + поворот кисти 90°/180°), приводящие нужную грань наверх; план сборки — вход среды (случайная последовательность или решение Kociemba), планирование не обучается.
- Инъекция сбоев (неудачи захвата, проскальзывания) и рандомизация (скорости примитивов, задержка старта) — источники приватной случайности партнёра.
- Метрический слой координации: occlusion-ablation, cross-play (zero-shot координация с незнакомым партнёром), recovery после сбоев; лестница экспериментов E1 → E2 → E2+ → E3 → E4.
- Запрет плейбека в демонстрации: дирижёр (жёсткая программа с oracle-информацией) — только sanity-проверка среды и верхняя граница, не демо.
- Режимы информации о партнёре: `none` / `oracle` / `predicted` (Bi-JEPA, отдельное изменение весной) / `predicted-direct` (классификатор примитива партнёра, baseline).

## Capabilities

### New Capabilities

- `skill-action-space`: дискретное пространство действий уровня навыков — выбор примитива каждой рукой, исполнение и прерывание примитивов, наборы примитивов по ролям, роль-симметричное расширение.
- `cube-environment`: многослотная среда сборки кубика — артикуляция кубика, блокировки слоёв, план как вход, инъекция сбоев, маски наблюдений, командная награда.
- `coordination-metrics`: измерение координации — occlusion-ablation, cross-play, recovery, вспомогательные метрики и критерии ступеней экспериментальной лестницы.

## Impact

- Код: `callosum/envs/` (новая среда навыков, билдер многослойного кубика), `callosum/envs/_skills.py` (чистая логика), `callosum/configs/`, `callosum/training/ippo.py` (категориальная голова), eval-harness в `scripts/`.
- Переиспользуется без изменений: физика `FaceTurn` (блокировки, трение, допуски), IPPO-тренер (логи, resume, защита от нефинитных состояний), автоматные примитивы эксперта (`callosum/experts/_phases.py`).
- Инфраструктура: аренда cloud GPU (взамен недоступного лабораторного сервера); локально на маке — только чистая логика и юнит-тесты.
- Из объёма исключено (весна, отдельные изменения): интеграция Bi-JEPA в политику (`predicted`), выученная моторика примитивов (архитектура B), VLA-сравнение, второй пример (общее рабочее пространство без плана).
