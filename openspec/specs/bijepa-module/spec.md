# bijepa-module Specification

## Purpose

Модуль Bi-JEPA в пространстве состояний: энкодеры, предсказатель латента партнёра, EMA target, анти-коллапс. Существующее поведение «как есть» (шаг 3.1, ветка `step/3.1-bijepa-module`, в `main` не влит; чистый PyTorch, тестируется на маке).

## Requirements

### Requirement: Энкодеры на агента

Модуль SHALL предоставлять MLP-энкодер на каждого агента: собственное наблюдение `o_i` → латент `z_i` (размер в конфиге `callosum/common/bijepa_config.py`). Энкодер получает **только собственное наблюдение агента** — тот же вход, что у политики без данных о партнёре.

#### Scenario: Формы латентов верны

- **WHEN** батч наблюдений проходит через энкодер
- **THEN** латент имеет сконфигурированную размерность на каждый элемент батча

### Requirement: Предсказатель партнёра по окну латентов

Предсказатель (MLP) SHALL предсказывать латент партнёра `ẑ_j` из истории собственных латентов (окно, flatten или GRU — опция конфига); цель `z_j` считается target-энкодером партнёра из его наблюдения и нужна только на обучении (CTDE). Горизонт предсказания — в конфиге (в решениях, не в шагах симуляции — для интеграции 3.2).

#### Scenario: Предсказание в обе стороны

- **WHEN** доступны латенты обоих агентов
- **THEN** `forward_both` возвращает MSE-лоссы предсказания в обе стороны (A→B и B→A)

### Requirement: EMA target-энкодер со stop-gradient

Цель предсказания MUST считаться EMA-копией энкодера партнёра; на цели стоит stop-gradient (градиент в target не течёт); `update_target()` вызывается после каждого шага оптимизатора. Оптимизатор собирается из `trainable_parameters()`.

#### Scenario: Градиент не течёт в цель

- **WHEN** выполняется forward + backward
- **THEN** у target-энкодера нет градиентов (проверено тестом на фиктивных тензорах)

### Requirement: Анти-коллапс по умолчанию

Анти-коллапс MUST быть включён по умолчанию: EMA-таргет + VICReg-подобный регуляризатор; `latent_stats()` возвращает std и эффективный ранг латентов для мониторинга (std не должен стремиться к 0, ранг не должен падать).

#### Scenario: Статистики латентов наблюдаемы

- **WHEN** обучение идёт
- **THEN** std и эффективный ранг латентов логируются через `latent_stats()` и остаются ненулевыми

### Requirement: Чистый PyTorch, тесты на маке

Модуль (`callosum/common/bijepa.py`, конфиг `callosum/common/bijepa_config.py`) MUST не зависеть от mani_skill; 24 теста (`tests/test_bijepa.py`) на фиктивных тензорах проходят на маке (`pytest`), линт чист.

#### Scenario: Юнит-тесты проходят без симулятора

- **WHEN** `uv run pytest tests/test_bijepa.py` запускается на macOS
- **THEN** 24 теста проходят: формы, forward+backward, stop-grad на цели
